# 生长之城 · Growing City Shanghai

以上海为蓝本的 3D 城市生长与生活仿真（Vite + three.js）。

> 说明：本项目使用他人的提示词，由 Claude Opus 5.5 生成。

## 运行

```bash
npm install
npm run dev
```

打开终端显示的地址（默认 http://127.0.0.1:5173）。

## 内容

- 城建动画：平整场地 → 河道 → 道路 → 跨江桥 → 分区建筑 → 街道设施
- 地标：东方明珠、金茂、环球金融中心、上海中心、外滩、南京路、人民广场、豫园、静安寺
- 交通：红绿灯、行人斑马线、早晚高峰潮汐、拥堵、事故
- 昼夜、天气、四季、烟花、上帝模式
- 仿真接口：`window.CitySim`（`src/main.js` 导出）
